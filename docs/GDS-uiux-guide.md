## 1. UX 라이팅

| 항목 | 규칙 |
|---|---|
| 어투 | 구어체·비격식체를 쓰되 프리미엄 카셰어링이라는 브랜드 방향성에 맞춰 정중하게. 정도 표현(너무·몹시·매우)은 오남용 금지. 표준 한국어 맞춤법 준수. |
| 헤더 타이틀 | 항상 페이지 타이틀 표기. "~하기" 또는 명사형(탭 메뉴는 명사형). 하위 페이지가 다수면 상위 페이지 타이틀. 다수 타이틀 표시 금지. |
| 문장형 타이틀 | 하오체. 행동 유도 페이지에서 3줄 이상 금지. 길어지면 쉼표·들여쓰기로 두 줄 분리. 한 페이지에 행동 유도는 하나만. 끝에 마침표 금지(물음표·느낌표는 가능). |
| 본문 | 부제목 설명이나 본문은 항상 마침표. 단 부제목이 "~하기"·"~기"·"~음"으로 끝나면 마침표 없음. 내용이 다르면 구분점·들여쓰기로 행 구분. |
| 플레이스홀더 | 입력할 텍스트가 무엇인지 알 수 있어야 함. 숫자는 필요한 자릿수를 알 수 있어야 함. |
| 알림 · 버튼 | 행동 유도 알림은 타이틀과 버튼명의 연관성 필요. 단순 안내의 버튼은 명사형. 결과 메시지는 구어체. 버튼이 2개 이상이면 표기 형식 동일("~하기"면 둘 다 "~하기"). |

## 2. 그래픽 (GUI)

**정의.** 마케팅에서 받은 심미적 콘텐츠 그래픽을 제외하고, 사용자 이용 여정(대여~반납) 화면에서 텍스트를 보조하고 UX 흐름을 지원하는 설명형 그래픽 요소.

### 2-1. 단계

정보 구조를 기준으로 나눕니다. 외형적 스타일이 기준이 아닙니다.

| 단계 | 이름 | 정보 구조 | 예 |
|---|---|---|---|
| Lv. 1 | 시스템 아이콘 | 단일 정보 구조 / 기능 수행 중심 | 뒤로가기 · 메뉴 · 검색 · 알림 |
| Lv. 2 | 커스텀 아이콘 | 설명 구조 포함(맥락 설명) | 상태 안내 아이콘 · 간단한 상황 표현 |
| Lv. 3 | 일러스트 | 복합 구조(상황 + 행동 + 흐름) | 촬영 가이드 · 반납 절차 안내 |

### 2-2. 기준 3가지

| | |
|---|---|
| 선택 기준 | 이 화면에서 사용자가 무엇을 이해해야 하는가 — 정보 구조로 분류하고 맥락으로 선택 |
| 예외 기준 | 같은 외형이라도 정보 구조가 다르면 단계가 달라집니다 |
| 밀도 기준 | 밀도는 단계 선택 기준이 아니라 표현 강도 조절 — 빠른 인지는 저·중밀도, 이해 필요는 고밀도 |

### 2-3. 원칙

- 문맥에 맞는 그래픽 — 꾸밈이 아니라 의미 이해를 돕는 역할
- 과도한 그래픽 밀도 자제
- 명확하고 단순한 2D 원칙. 3D(입체·아이소메트릭)는 일관성·확장성·유지보수 비효율로 지양
- [이미지 + 텍스트]는 폰트를 임의로 변경하지 않음

## 3. 컴포넌트 정의

컴포넌트는 텍스트·그래픽·인터랙션 요소가 결합되어 하나의 기능 또는 정보를 전달하는 UI 단위. 카드·리스트 등은 컴포넌트이며 그래픽 분류 대상이 아닙니다.
